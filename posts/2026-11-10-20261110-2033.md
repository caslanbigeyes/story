### 1. Event Loop 这篇你看完就不用再看别的了！

- 文章来源平台：掘金
- 原文链接：<https://juejin.cn/post/7705651336889696310>

**AI 总结**

- Event Loop 涉及浏览器渲染流水线，而非仅 JavaScript 引擎调度逻辑。
- 宏任务队列包含 setTimeout、setInterval、用户交互等，每轮 Event Loop 只执行一个宏任务。
- 微任务在宏任务执行完毕后一次性清空，可能造成性能问题。
- requestAnimationFrame 在渲染前执行，适合动画，而 setTimeout 时机不可控。
- 渲染流水线包括 Style、Layout、Paint、Composite 四步，影响前端性能。
- requestIdleCallback 适合做不紧急的工作，如数据预加载、日志上报等。
- 结论：理解 Event Loop 和渲染流水线对前端性能优化至关重要。

- Harness Engineering 不是工具拼盘，而是关注能力如何在真实仓库中被约束和反馈。
- 代码生成能力提升后，工程环境复制变得更重要，包括 AGENTS.md 模板、目录约束、lint、结构测试等。
