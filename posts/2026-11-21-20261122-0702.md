### 1. 理解 JavaScript 对象、原型与包装类

- 文章来源平台：掘金
- 原文链接：<https://juejin.cn/post/7710090550490710026>

**AI 总结**

- JavaScript 数据类型分为基本类型和引用类型，基本类型包括 number、string、boolean 等，引用类型包括 object、array、function 等。
- 原始值在定义时不会立即创建对象，只有在访问属性或方法时才会自动创建包装类临时对象。
- 构造函数用于批量创建结构相同的对象实例，通过 new 关键字调用。
- 函数的显式原型（prototype）和对象的隐式原型（__proto__）是 JavaScript 对象机制的核心，实例的隐式原型指向构造函数的显式原型。
- 包装类允许原始值调用方法，但属性保存在临时对象上，对象销毁后无法读取。
- “万物皆是对象”是通俗说法，引用类型本身就是对象，原始值通过包装类机制临时成为对象。

- 结论：理解 JavaScript 对象、原型与包装类对于深入掌握 JavaScript 语言至关重要。
