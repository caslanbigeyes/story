### 2. 为什么 Clean Architecture 能让 ViewModel 保持轻量？

- 文章来源平台：掘金
- 原文链接：<https://juejin.cn/post/7647072739918184458>

**AI 总结**

-  Clean Architecture 通过职责分离，使 ViewModel 保持轻量，专注于管理 UI 状态。
-  传统 MVVM 架构中，ViewModel 可能承担过多职责，导致难以维护和扩展。
-  Clean Architecture 将业务逻辑、数据流和 UI 逻辑分离，提高代码可维护性和可复用性。
-  ViewModel 负责接收 UI 事件，调用 UseCase，转换 UI 状态。
-  UseCase 负责处理业务规则和业务流程，输出明确的业务结果。
-  Repository 负责数据访问，屏蔽具体数据来源。
-  使用 suspend Result 或 Flow/StateFlow 来处理一次性操作或持续状态。
-  结论：Clean Architecture 通过清晰的职责划分，有效避免 ViewModel 膨胀，提高 Android 开发的可维护性和可扩展性。
