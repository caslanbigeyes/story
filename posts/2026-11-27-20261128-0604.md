### 4. async/await 和 Promise 到底怎么选？

- 文章来源平台：掘金
- 原文链接：<https://juejin.cn/post/7711798594807037979>

**AI 总结**

- async/await 是 Promise 的语法糖，返回 Promise 本身。
- async/await 适合线性流程，Promise 适合并发处理。
- async/await 提高了错误处理效率，但 try/catch 范围有限。
- await 会将代码打包成 continuation，影响执行顺序。
- return 和 return await 有区别，影响 finally 执行。
- forEach 中使用 async 回调会导致 Promise 丢失。
- 串行 await 可能导致性能问题。

- 结论：根据具体场景选择 async/await 或 Promise，优化代码结构和性能。
