### 1. __proto__ vs prototype：90% 的人分不清的 JavaScript 核心

- 文章来源平台：掘金
- 原文链接：<https://juejin.cn/post/7648213611392172051>

**AI 总结**

- JavaScript 中每个对象都有一个 `__proto__` 属性，指向其构造函数的原型对象。
- `prototype` 属性仅存在于函数对象上，指向该函数的实例共享的原型对象。
- 原型链是 JavaScript 中实现继承的关键机制，通过 `__proto__` 连接。
- `__proto__` 是一个 getter/setter，推荐使用 `Object.setPrototypeOf` 和 `Object.getPrototypeOf` 替代。
- 函数也是对象，有自己的 `__proto__`，指向 `Function.prototype`。
- `new` 关键字通过创建一个新对象，设置其 `__proto__` 指向构造函数的 `prototype` 来实现对象创建。
- ES6 的 `class` 语法糖本质上也是基于原型链的。

- 结论：理解 `__proto__` 和 `prototype` 是掌握 JavaScript 继承和原型链机制的关键。
