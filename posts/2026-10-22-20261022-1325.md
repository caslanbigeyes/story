- 代理通过 API 创建，Omnara 负责运行代理循环、提供运行命令的沙箱、处理秘密、权限和 RBAC。
- 代理状态存储在 PostgreSQL 中，确保代理在重启时能够恢复，且在空闲时无需成本。

- 与 Claude Managed Agents 和 OpenAI Agents API 类似，但 Omnara 是开源版本，可在用户自己的服务器上运行并使用自己的模型。
- 采用无状态工作员在控制平面运行循环，支持跨不同机器和进程运行代理循环的迭代。
- 支持连接多种机器，如笔记本电脑和云沙箱，实现代码同步和持续工作。
- 整个代码库开源，可使用 Docker Compose 在单机上自托管。

- 结论：Omnara 提供了一种灵活且可扩展的代理运行环境，适用于需要持久性和跨平台操作的场景。
