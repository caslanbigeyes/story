### 4. 为什么 Android 非要用 Intent 传值？

- 文章来源平台：掘金
- 原文链接：<https://juejin.cn/post/7682633827693838388>

**AI 总结**

- Android 采用 Intent 传值而非直接引用，因系统可随时销毁组件，保证数据可恢复。
- 消息驱动设计避免内存泄漏和崩溃，Intent 和 Binder 传递序列化消息。
- Activity Result API 提升开发体验，但底层仍依赖系统消息分发。
- HarmonyOS 融合 Android 和 iOS 优点，应用内通信由应用管理，跨应用由系统接管。
- 理解内存控制权和安全边界，解耦状态数据和 UI 组件，适应不同系统架构。
- 结论：Android 的 Intent 传值设计是基于系统架构和安全性考虑，而非简单的 API 使用习惯。
