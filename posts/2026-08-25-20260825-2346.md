- 文章来源平台：掘金
- 原文链接：<https://juejin.cn/post/7677762452274085914>

**AI 总结**

- 模型无法直接读取本地文件，需通过工具请求和执行机制。
- 文件读取涉及用户、模型、Harness、工具函数和文件系统等多个参与者。
- Tool Schema 和 Tool Executor 分别定义工具的说明和执行函数。
- 模型通过 Tool Call 提出读取文件请求，Harness 校验后执行。
- 路径校验确保工具读取文件的安全性和限制范围。
- 文件读取完成后，内容通过 Tool Result 返回给模型。
- 当前实现只能读取一次文件，未形成完整的 Agent Loop。

- 结论：AI Agent 读取文件的过程涉及多环节协作，确保模型与外部世界交互的安全性和有效性。
