### 3. Chromium和Chrome到底是什么关系?

- 原文链接：<https://juejin.cn/post/7678271004720431156>

**AI 总结**

- Chromium 是开源浏览器工程，Chrome 是基于 Chromium 的浏览器产品。
- Chromium 由 Google 发起并主导，多个公司和个人参与开发。
- Chromium 包含浏览器所需的基础设施，而非单纯的内核。
- Chrome 基于 Chromium，增加了 Google 的产品功能。
- Blink 是 Chrome 和 Chromium 的网页渲染引擎，V8 是 JavaScript 引擎。
- Chrome 和 Edge 使用相同的 Chromium 底座，但上层产品不同。
- Safari 和 Firefox 使用不同的浏览器实现，如 WebKit 和 Gecko。
- Chrome 内部采用多进程架构，提高稳定性和安全性。
- Chrome DevTools 提供观察 Chromium 能力的窗口。
- 结论：Chromium 和 Chrome 是紧密关联但不同的项目，Chromium 是基础，Chrome 是基于 Chromium 的完整浏览器产品。
