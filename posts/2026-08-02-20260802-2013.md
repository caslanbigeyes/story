### 3. workFlow 和 Agent 究竟是什么？他们的区别是什么？

- 文章来源平台：掘金
- 原文链接：<https://juejin.cn/post/7668232302212104238>

**AI 总结**

-  Workflow 是预先定义的执行流程，类似工厂流水线，每个节点有明确输入输出。
-  Agent 是自主决策的执行体，根据目标自主探索完成任务路径。
-  Workflow 优势在于确定性、稳定性和可控性，适用于流程固定、重复性高的任务。
-  Agent 优势在于灵活性和适应性，适用于开放场景、非结构化需求。
-  产业落地中，常采用 Workflow 和 Agent 的混合架构，以实现稳定性和智能性的平衡。
-  结论：Workflow 和 Agent 是互补的，应根据具体场景选择合适的组合方式。
