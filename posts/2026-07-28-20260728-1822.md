### 4. 腾讯面试官：“你说你做了一个终端Agent，那说说 LLM 和 Agent的区别，ReAct、MCP、Tool、Memory、Skills？”我信誓旦旦开始背了

- 文章来源平台：掘金
- 原文链接：<https://juejin.cn/post/7667008177453252659>

**AI 总结**

- LLM 和 Agent 区别：LLM 是无状态的文本生成服务，Agent 是围绕 LLM 的执行系统，负责执行决策。
- Agent 功能：包括工具调用、循环处理、记忆管理。
- ReAct Agent 组成：模型客户端、工具注册表、工具执行器、循环控制、上下文管理。
- Agent 框架模块：入口层、Agent 层、模型层、工具层、记忆与上下文层、安全层。
- MCP 和 tool 区别：tool 是应用内函数，MCP 是独立服务进程，支持不同应用连接。
- 短期记忆和长期记忆：短期记忆为会话内消息历史，长期记忆为跨会话的用户目录记忆库。
- Skill 渐进式加载：索引常驻，正文按需加载，降低常驻成本。
- AI 输出内容质量保证：写后自检、审查重试、安全兜底、提示词优化。 
- 学习建议：了解模型运行、缓存机制、输出稳定性、Skill 运转逻辑、MCP 和 tool 机制、上下文管理、RAG 知识管理等。 
- 结论：AI 时代，理解和应用 Agent 技术是关键，需不断学习相关知识和实践。
