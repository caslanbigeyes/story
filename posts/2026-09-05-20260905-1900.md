### 7. Windows 11 彻底关闭 Hyper-V 的办法

- 文章来源平台：V2EX
- 原文链接：<https://www.v2ex.com/t/1239688>

**AI 总结**

- 1. Windows 11 Build 26200 中，关闭 Hyper-V 和 VBS 后，Smart App Control 需要关闭以彻底禁用虚拟化功能。
- 2. 通过“启用或关闭 Windows 功能”取消勾选 Hyper-V 相关项目，包括 Hyper-V、Windows Hypervisor Platform 等。
- 3. 关闭“内存完整性”功能，但不影响 LSA Protection、易受攻击的驱动程序阻止列表和内核 DMA 保护。
- 4. 使用管理员权限执行命令关闭 Hyper-V Hypervisor 启动，并检查状态。
- 5. 通过注册表编辑器关闭 VBS、Credential Guard 和 HVCI。
- 6. 重启 Windows 后，使用 PowerShell 和 msinfo32 验证 Hyper-V 和 VBS 是否关闭。
- 结论：彻底关闭 Windows 11 的 Hyper-V 和 VBS，使 VMware Workstation 直接使用硬件虚拟化功能。
